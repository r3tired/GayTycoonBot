## Запуск

1. `npm install`
2. Впиши токен бота в `bot.env` у змінну `BOTTOKEN`.
3. Дай боту право **Manage Roles** і підніми його роль вище ігрових ролей.
4. Запусти: `npm start` (або `npm run dev` з автоперезапуском).

Бот реєструє slash-команди, синхронізує ролі з `data/roles.js` і за командою `/start`
створює клуб із початковим балансом та зонами першого рівня. `/profile` показує баланс
і дохід клубу, `/collect` збирає пасивний дохід, а `/upgrade` прокачує зони за кнопками.
Зони, їхні ціни та доходи налаштовані у `data/zones.js`. Зупинити бота: `Ctrl+C`.

Ігровий прогрес зберігається у SQLite (`database/game.sqlite`), окремо для кожного
гравця на кожному сервері. `/start` доступна один раз; попередні відмітки з
`database/startClaims.json`, якщо файл є, переносяться до бази даних під час запуску.
Дохід накопичується без часового ліміту. Якщо у гравця вже є роль з іншої групи,
стартова група не видається.

Не додавай `bot.env` до архівів або репозиторію: файл містить секрети. Він уже
виключений через `.gitignore`.

## Логи

Усе, що бот виводить, і всі помилки (разом з аварійним завершенням) пишуться у `logs/bot.log`.

- Прочитати в терміналі: `npm run logs` (останні 50 рядків), `npm run logs -- 200`, `npm run logs -- errors`
- Прочитати в Discord: `/logs` (лише для власника, ID береться з `CREATORID` у `bot.env`)
- Файл можна відкрити й вручну: `logs/bot.log`
